# 오늘의 수학 학습 (삼각비 · 원의 성질)

**흐름:** 학번 로그인 → 단원 선택(삼각비 / 원의 성질) → 개념 정리 · 퀴즈 → 학습 리포트

## 기능
- **개념 정리 (드래그 시각화)**
  - 삼각비: 직각삼각형 실험, 단위원 위 점 P 드래그, **각에 따른 sin · cos · tan 변화 실험실**(그래프 · 재생 · 기록표 · 결과 정리 문제)
  - 원의 성질: 원주각과 중심각(점 P·Q 이동, 보조선), 접선과 현이 이루는 각
- **퀴즈 (단원별 문제 은행 50문항: 하·중하 40 + 중상 10 → 한 번에 30문항 = 하·중하 20 무작위 + 중상 10, 쉬운 문제부터)**
  - 틀리면 정답 대신 1단계 개념 → 2단계 수식 → 3단계 해설 순으로 힌트
  - 고른 오답에 맞춘 안내 (예: "혹시 중심각의 1/2을 안 하셨나요?")
  - 첫 시도 정답마다 도토리 1개, 10개 = 칭찬 도장 1개
- **리포트 · 배지:** 이해도 점수, 약한 개념 1가지, 자주 한 실수, 도전과제 배지 7종

## 파일 구성
| 파일 | 내용 |
|---|---|
| `index.html` | 모든 화면 |
| `style.css` | 디자인 |
| `js/geometry.js` | 도형 그림, 드래그 도구, 변화 실험실 |
| `js/questions.js` | 개념 · 오답 유형 · 배지 · 문제 은행 (문제 추가는 여기서) |
| `js/app.js` | 로그인, 보상, 퀴즈 진행, 리포트, 시트 전송 |
| `gas/Code.gs` | Google Apps Script 백엔드 |

## 실행
`index.html`을 브라우저로 열면 됩니다. (VS Code Live Server 추천)

## Artigraphy 이미지로 바꾸기
배경을 제거한 PNG를 `assets/acorn.png`, `assets/stamp.png`로 저장하고 `js/app.js`의 `CONFIG.IMG` 경로를 바꿉니다.

## 구글 시트 연결
1. 새 구글 시트 → 확장 프로그램 → Apps Script → `gas/Code.gs` 붙여넣기
2. 배포 → 새 배포 → 웹 앱 (실행: 나 / 액세스: 모든 사용자) → URL 복사
3. `js/app.js`의 `CONFIG.GAS_URL`에 붙여넣기

`퀴즈기록` 탭에 학번 / 단원 / 점수 / 이해도 / 소요시간 / 힌트 사용 / 틀린 개념 / 오답 유형 / 약한 개념이 쌓이고,
`학생현황` 탭에는 학번별 최신 도토리 · 도장 · 배지가 정리됩니다.

이미지 주소가 `https://bjh97510-lab.github.io/tricir/` 기준이라 **GitHub Pages가 켜져 있어야** 보입니다. 주소가 바뀌면 `og:url`, `og:image`, `twitter:image`를 함께 고쳐 주세요.
